# 🎓 Kampüs Etkinlikleri (Campus Events Web Application)

Modern ve kullanıcı dostu bir arayüze sahip, üniversite kampüsündeki etkinliklerin duyurulduğu, filtrelendiği ve yönetildiği tek sayfa tabanlı bir web uygulaması (SPA).

---

## 🚀 Öne Çıkan Özellikler

- **Dinamik HSL Renk Teması:** CSS değişkenleri (`--renk-ana`, `--renk-zemin`) ve rastgele ton algoritmasıyla modern bir görsel kimlik.
- **Gelişmiş Etkinlik Filtreleme:** Etkinlikleri kategoriye ve tarihe göre hızlıca arama ve filtreleme.
- **Kullanıcı Doğrulama (Auth):** Şifre uzunluk kontrolü (en az 6 karakter), e-posta doğrulama ve dinamik hata geri bildirimlerine sahip Giriş Yap (`/login`) ve Kayıt Ol (`/register`) sayfaları.
- **Yönetim Paneli (Admin):** Etkinlik ekleme, düzenleme ve silme operasyonları için tablolu yönetim arayüzü.
- **Tam Duyarlı (Responsive) Tasarım:** Mobil cihazlardan büyük masaüstü ekranlara kadar kusursuz uyum sağlayan esnek CSS Grid ve Flexbox yerleşimi.

---

## 🛠️ Kullanılan Teknolojiler

Bu proje, modern web standartlarına uygun olarak sıfırdan vanilla tabanlı mimari ve React ekosistemiyle geliştirilmiştir:

- **React & TypeScript:** Güçlü tip güvenliği ve bileşen tabanlı mimari.
- **React Router:** Sayfalar arası akıcı yönlendirme (SPA routing).
- **Vite:** Çok hızlı geliştirme ve üretim (build) ortamı.
- **CSS3 / Palatino Linotype:** Özel tipografi, HSL renk paleti ve modern UI stilleri.
